# Year 1 musculoskeletal: sentence cut and graph check (2026-11-18)

## What was wrong
`outline.py` cut the sections by page only. Lesson k got every line of its pages, and each boundary page is shared
by two lessons (e.g. page 16 holds the end of Axilla and the start of Shoulder region). So 38 boundaries overlapped,
1099 lines sat in two sentences, and `i0` broke 38 times. The page ranges were right; the cut inside a shared page
was not.

## What changed
- `cut.py` (this folder) cuts each lesson at its `start` line from `reference.json`: the line that reads as the
  lesson's title, on its first page. Lesson k runs up to the line before lesson k+1's start. Heading rules are still
  `outline.is_heading`. All 39 start lines were found on their first page, in order.
- `outline.json` rewritten: 672 sentences (was 744). Every line is now in exactly one sentence. The count fell
  because the old cut counted the shared-page lines twice and shifted section starts on those pages (28 old section
  start lines are no longer starts; not every drop is a duplicate, so no per-sentence mapping is claimed).
  The old file is kept at `old/outline_pages_only_2026-11-18.json`.
- `graph/`: the old `sentences.jsonl`, `graph.json`, `chapters.json` are kept as `graph/old/*_pages_only_2026-11-18.*`.
  Rebuilt with `py -m spine graph build year1-musculoskeletal` (5918 sentences; 5824 in a lesson, 94 front matter).
