### Rules the job follows
- Keys come only from Telegram's correct flag. Never infer or fix one.
- **Our own votes never count** (owner order): every vote is logged in table `own`, and `net()` removes it. Old jobs always clicked option 0; `seed_old_keys` removes those too. Old counts already on the live site were not corrected.
- A quiz hides results from accounts that have not voted, so the key is saved at vote time, per account. A later scrape cannot read it.
- One vote per distinct question, using the zero-lossy rule (`wordKey` in `backend/src/scripts/importSfQuestions.ts`, ported as `word_key`). The owner's "all vote" means all accounts work, not that each poll gets 7 votes.
- Accounts join missing channels by themselves. An account that logs in during a run joins within a minute. A signed-out account stops alone.
